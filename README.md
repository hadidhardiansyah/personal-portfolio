# Hadid's Digital Portfolio

Welcome to the source code of my interactive, highly scalable personal portfolio. 

As a **Software Engineer and System Architect**, I believe that architecture is more than just writing code—it's about making conscious, long-term commitments to chosen patterns, deeply understanding the problem domain, and building with irrational loyalty to quality. 

This repository isn't just a static site; it's a living showcase of modern web engineering, blending robust structural patterns with an immersive user experience.

## 🏗️ Architectural Philosophy

Built with a **Human Architect Mindset**, this project emphasizes:
- **Systems Thinking:** Seamlessly integrating reactive frontend interfaces (Vue 3) with rich 3D graphics (ThreeJS) without sacrificing performance or scalability.
- **Loyalty to Coherence:** Sticking rigorously to modern utility patterns (Tailwind CSS) and centralized state management, resisting the fragmentation of "shiny object syndrome" to maintain a solid, boringly reliable foundation.
- **User-Centric Design:** Utilizing fluid micro-animations (GSAP) and immersive glassmorphism layouts that respect the user's cognitive load and focus.

## 🚀 Tech Stack

- **Framework:** Vue 3 (Composition API) + Vite
- **Styling:** Tailwind CSS
- **Animations:** GSAP & ScrollTrigger
- **3D Graphics:** ThreeJS (WebGL)

## 🌟 Key Features

- **Immersive 3D Backgrounds:** A dynamic, interactive WebGL environment featuring a rotating MacBook and floating geometric nodes that flow consistently across pages.
- **Animated Project Modals:** A highly modular, transition-rich popup system that presents architectural case studies (Frontend, Backend, Mobile) without breaking the user's spatial context.
- **Custom Cursor Interaction:** A bespoke cursor system that intelligently reacts to interactive DOM elements, elevating the premium feel of the UI.
- **Responsive & Accessible:** Fully optimized for all devices, ensuring the 3D canvas and complex grid layouts gracefully degrade on mobile screens.

## 🛠️ Local Development

To run this project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/hadidhardiansyah/personal-portfolio.git
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Start the development server:**
   ```bash
   npm run dev
   ```
